# ferrobridge

The runtime of the safe Rust API that [ferrobridge](https://github.com/SirAlper/ferrobridge) generates from C++ headers.

ferrobridge reads C++ headers with libclang, takes ownership information from a small annotation file (`ferrobridge.toml`) and generates a [cxx](https://cxx.rs) bridge, a C++ shim and a safe, idiomatic Rust API on top of it. The generated code depends on this crate for:

- `ferrobridge::Error` / `ferrobridge::Result`: one error type for every generated API (C++ exceptions, invalid UTF-8, unknown enum values...), so errors from different bridges combine with `?`;
- `ferrobridge::include_bridge!`: includes a bridge generated during the build (`ferrobridge-build` with the `generate` feature);
- conversion helpers used by the generated safe layer (not meant to be called by hand).

```toml
[dependencies]
cxx = "1.0"
ferrobridge = "0.1"

[build-dependencies]
ferrobridge-build = "0.1"
```

```rust
// The safe API generated for a C++ class `geo::Vehicle`; no `unsafe`, `Pin` or cxx types.
fn main() -> ferrobridge::Result<()> {
    let mut car = vehicle::Vehicle::new_i32(4)?; // C++ constructor
    car.drive(12.5)?;                            // a C++ exception comes back as `Err`
    Ok(())
}
```

**Version rule:** code generated by ferrobridge `0.x.y` needs this crate at `0.x` (the same minor version). The generator version is written in the first line of every generated file (ADR-0012).

Getting started, the annotation file and the full type mapping: the [ferrobridge README](https://github.com/SirAlper/ferrobridge#readme).
